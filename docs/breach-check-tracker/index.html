Breach Check Tracker

List every email address and alias you actually use, then check each one on Have I Been Pwned yourself once a quarter. This page never looks anything up for you — it only remembers which addresses you've checked and when.
Why this exists: Domain 1 and Domain 8 of the Playbook both recommend a Have I Been Pwned check as a free, do-this-first step — but until now nothing on this site made that a trackable habit the way the Broker Removal Tracker does for opt-outs. This tool deliberately does not query any breach database itself: it would need a backend and your email to do that server-side, which is exactly the kind of feature Spidergraph's own scope rules out (see the Playbook, or CLAUDE.md if you're a contributor). Instead, add your own addresses below, click through to Have I Been Pwned to check each one yourself, and tick it off — same shape as the rest of this site: you provide the input, you do the verification, this page just remembers your progress.
